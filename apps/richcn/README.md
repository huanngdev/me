# richcn

A demo app for the notion-like rich text editor that lives in `@repo/core`. It has a header and the editor, and nothing else.

Run it from the repo root with `bun run dev` inside this folder (`cd apps/richcn && bun run dev`). The dev server listens on port 3001 so it does not clash with `apps/web` on port 3000.

Pages: `/` (the editor demo) and `/docs` (a short note with a link to the editor README).
